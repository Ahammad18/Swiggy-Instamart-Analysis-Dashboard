
# 🛵 Swiggy Instamart Sales Dashboard – Power BI Project

This Power BI report provides a comprehensive analysis of sales performance for Swiggy Instamart outlets across different categories and regions. The dashboard is visually engaging and interactive, aimed at helping business stakeholders understand key sales metrics and operational performance.

## 📊 Dashboard Highlights

- **💰 Total Sales:** $1.2M
- **🧾 Number of Items Sold:** 8,523
- **💵 Average Sales per Transaction:** $141
- **⭐ Average Customer Rating:** 3.9

## 🔍 Key Insights

- **Outlet Establishment Trends:** Visualizes how new outlets have been established over time, showing peak growth years.
- **Fat Content Breakdown:** Compares sales and quantity of Low Fat vs Regular products.
- **Outlet Tier Performance:** Shows Tier 3 outlets generating the highest revenue ($472K), followed by Tier 2 and Tier 1.
- **Outlet Size Comparison:** Small outlets lead in sales contribution.
- **Top Item Categories:** Includes Fruits, Snacks, Household Items, Frozen Foods, and more.
- **Outlet Type Analysis:** Breaks down performance across Grocery Stores and multiple Supermarket types.

## 🧰 Features

- **Interactive Filters** on:
  - Outlet Location Type
  - Outlet Size
  - Item Type
- **Dynamic KPIs** updating based on filter selections
- **Custom visuals** including bar charts, line graphs, and donut charts

## 🚀 How to Use

1. Download the `.pbix` file
2. Open it in [Power BI Desktop](https://powerbi.microsoft.com/)
3. Interact with filters and visuals to explore insights

## 📌 Purpose

This project demonstrates the use of Power BI for retail sales analysis, showing how visual analytics can be used to guide business decisions in the food delivery and retail segment.
